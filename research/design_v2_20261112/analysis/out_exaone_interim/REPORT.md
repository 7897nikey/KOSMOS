# K-EXAONE 2.5 중간 결과 — 설계 v2 본 분석 프레임 (2026-11-15 갱신)

> **잠정 결과.** EXAONE 표본이 아직 다 모이지 않았다. 나머지(태우 일부, 이지은 몫)가 모이면 같은 스크립트로 다시 계산하고, 그때 test 49문항을 한 번만 연다.
> 2026-11-14 판은 허다교+태우(프롬프트당 46표본)였고, 이번 판은 정주희(m2) 25–49 완료분을 더한 **프롬프트당 69~73표본(중앙값 72)** 이다. 결론은 같고 수치만 조금 움직였다.

| 항목 | 내용 |

## 핵심 결과

### 1. 분포 거리: EXAONE이 세 모델 중 사람과 가장 가깝다

**validation 49문항, β* 보정 후 TVD** (낮을수록 좋음)

| 단계 | EXAONE | DeepSeek | Haiku | 균등분포 |
|---|---:|---:|---:|---:|
| c0 | 0.301 | **0.289** | 0.301 | 0.335 |
| L0 | **0.247** | 0.270 | 0.293 | 0.335 |
| L1 셀별 | **0.251** | 0.290 | 0.287 | 0.353 |

- 같은 문항끼리 짝지어 비교하면 L1에서 EXAONE이 DeepSeek보다 0.040, Haiku보다 0.038 낮다. 두 차이 모두 95% 구간이 0을 포함하지 않는다.
- L0에서는 Haiku보다 0.049 낮고(구간이 0을 포함하지 않음), DeepSeek보다는 0.022 낮지만 구간이 0을 포함한다.
- c0에서는 세 모델의 차이가 없다.
- 보정 전(β=1, 197문항)에는 차이가 더 크다. EXAONE은 L0에서 DeepSeek보다 0.049, Haiku보다 0.120 낮고 모두 유의하다.
- W1(서열·이진형)도 순서가 같다. L1 β*에서 EXAONE 0.127, DeepSeek 0.142, Haiku 0.144다.

### 2. 페르소나 한 줄은 EXAONE에서만 효과가 있다

**c0 → L0일 때 TVD 변화** (β=1, 197문항)

| 모델 | 변화 | 95% 구간 | 개선된 문항 비율 |
|---|---:|---|---:|
| EXAONE | **−0.057** | [−0.085, −0.030] | 60% |
| DeepSeek | −0.012 | [−0.036, 0.011] | 52% |
| Haiku | −0.013 | [−0.038, 0.012] | 40% |

- EXAONE은 "한국 성인입니다"라는 한 줄이 붙으면 덜 쏠린다.
  - 최빈 보기 ≥90%인 문항 비율: 54% → 34%
  - 정규화 엔트로피: 0.25 → 0.34
- L0 → L1(성별·연령)로 가도 세 모델 모두 모집단 거리는 거의 변하지 않는다(구간이 모두 0을 포함).

### 2-1. 단계별 쏠림 사다리

| 단계 | EXAONE 엔트로피 / 최빈≥90% | DeepSeek | Haiku | 사람 |
|---|---|---|---|---|
| c0 | 0.25 / 54% | 0.32 / 46% | 0.16 / 76% | 0.74 / 4% |
| L0 | 0.34 / 34% | 0.31 / 44% | 0.17 / 71% | 0.74 / 4% |
| L1 셀별 | 0.36 / 32% | 0.33 / 41% | 0.14 / 76% | 0.72 / 4% |

### 3. 쏠림(모드 붕괴)은 세 모델 모두 심하다

| (L0, 197문항) | EXAONE | DeepSeek | Haiku | 사람 |
|---|---:|---:|---:|---:|
| 정규화 엔트로피 (1=균등) | 0.34 | 0.31 | 0.17 | 0.74 |
| 최빈 보기 비율 평균 | 0.79 | 0.82 | 0.90 | 0.53 |
| 최빈 보기 ≥90%인 문항 | 34% | 44% | 71% | 4% |

- 그래서 β*가 모두 1보다 훨씬 작다(EXAONE 0.335~0.385, DeepSeek 0.325~0.33, Haiku 0.26~0.27). β를 낮춰 분포를 펴야 균등분포를 이긴다.
- 보정 없이(β=1) 균등분포를 이기는 건 197문항 기준 EXAONE L1(0.356, 균등 0.361) 하나뿐이고 차이도 거의 없다. validation 49문항만 보면 이것도 비긴다(0.357 vs 0.353).
- 민감 문항일수록 더 쏠리는가(민감도와 초과 쏠림의 스피어만 ρ)를 보면, 세 모델 모두 |ρ| ≤ 0.1이고 구간이 0을 포함한다. 이 가설은 지지되지 않는다.

### 4. 최빈값 정확도: 모델 간 차이가 없다

**197문항, 보정 전 원비율**

| 단계 | EXAONE 엄격 / RADIUS | DeepSeek | Haiku | 우연(엄격 / RADIUS) |
|---|---|---|---|---|
| c0 | 0.52 / 0.62 | 0.50 / 0.58 | 0.53 / 0.60 | 0.26 / 0.30 |
| L0 | 0.49 / 0.57 | 0.50 / 0.58 | 0.53 / 0.62 | 0.26 / 0.30 |
| L1 셀별 | 0.53 / **0.76** | 0.48 / 0.68 | 0.56 / 0.76 | 0.26 / 0.41 |

- 세 모델 모두 우연보다 두 배쯤 높지만, 모델 간 차이의 구간은 대부분 0을 포함한다.

### 5. 집단 구분(L1 셀 간 순서): EXAONE ≈ DeepSeek > Haiku

**셀 쌍 순위 AUC**: 서열·이진형 문항, 사람 쪽 차이가 유의한 쌍만 센다(RADIUS 규칙, 주 결과).

| 쌍 | EXAONE | DeepSeek | Haiku |
|---|---:|---:|---:|
| 전체 (1,745쌍) | **0.743** [0.69, 0.79] | 0.740 [0.69, 0.79] | 0.633 [0.59, 0.67] |
| 연령만 다름 (779쌍) | 0.764 | 0.770 | 0.639 |
| 성별만 다름 (115쌍) | 0.600 | 0.557 | 0.557 |

- 연령 차이는 잘 잡지만 성별 차이는 셋 다 우연(0.5) 근처이고 구간이 0.5를 포함한다(EXAONE [0.51, 0.68]은 하한이 간신히 걸친다).
- Haiku는 셀 간 동점이 34%다. 셀이 바뀌어도 같은 답을 내는 경우가 많다는 뜻이다.
- 셀 안 보기 순서 AUC(BPR식, L1)는 EXAONE 0.768, DeepSeek 0.702, Haiku 0.669이다. 모집단 사람 순서를 그대로 쓰는 기준선은 0.937이라, 셋 다 크게 못 미친다.
- 셀 간 차이를 과장하는 정도(L0 대비 셀 이동 TVD, 사람은 0.080)는 EXAONE 0.164, DeepSeek 0.200, Haiku 0.236이다. EXAONE이 가장 덜 과장한다.

## 한 줄 요약

K-EXAONE 2.5는 세 모델 중 **분포가 가장 덜 쏠리고, 페르소나에 맞춰 분포가 실제로 움직이는 유일한 모델**이다. 다만 최빈값을 맞히는 능력과 집단 순서를 구분하는 능력은 DeepSeek와 같은 수준이고, 성별 차이는 어느 모델도 확실히 잡지 못한다.

## 한계

- **잠정치다.** 프롬프트당 약 72표본이다. DeepSeek·Haiku를 72표본에서 100표본으로 늘리면 β=1 TVD가 0.006~0.010 올라간다(`k_sensitivity.csv`; 46표본일 때는 0.017~0.024). 모델 간 비교는 표본 수를 맞췄으므로 공정하지만, 절대값은 최종 결과와 다를 수 있다.
- validation이 49문항뿐이라 최빈값처럼 0/1로 떨어지는 지표는 구간이 넓다(±0.1~0.2).
- EXAONE은 추론을 끌 수 없어 reasoning_effort=low로 돌렸다. DeepSeek은 추론을 껐고(none), Haiku는 thinking을 껐다. 생성 조건이 완전히 같지는 않다.
- `frozen_beta.json`은 건드리지 않았다. 최종 β*는 100표본이 모인 뒤 정한다.
- 팀원 표본 구간이 다르다. 표본 번호별로 실행 날짜·시간대가 달라 API 쪽 상태가 달랐을 수 있다(m2는 11/12·11/13·11/15 3일에 걸쳐 실행). 아직 확인하지 않았다.
