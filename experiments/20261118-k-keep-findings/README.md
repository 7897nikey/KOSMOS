## 질문 (돌리기 전에 쓴다)

DeepSeek Eco 추론 끔/low 실험을 몇 회(k)로 돌리면 충분한가. 기준은 "k=100에서 얻은 결론이 줄인 k에서도 그대로 나오는가"다.

## 판정 기준 (돌리기 전에 쓴다)

결론 다섯 개를 모델별로 본다(3모델 × 5 = 15개).

| | 결론 | 범위 | 유의 판단 |
|---|---|---|---|
| F1 | 페르소나 한 줄 효과: c0→L0 TVD 변화 (β=1) | test 제외 197문항 | 문항 부트스트랩 95% 구간이 0을 안 포함 |
| F2 | 셀 세분화 효과: L0→L1 TVD 변화 (β=1) | 197문항 | 같음 |
| F3 | 셀 간 순서: 사람 쪽 유의쌍 AUC (RADIUS) | 197문항 서열·이진 | 구간이 0.5를 안 포함 |
| F4 | 셀 안 보기 순서 AUC (BPR식, L1) | 197문항 | 구간이 0.5를 안 포함 |
| F5 | 보정(β*)이 균등분포보다 낫다: TVD(β*) − TVD(균등), L1 | validation 49문항 (β*는 calibration에서) | 구간이 0을 안 포함 |

- k=100의 판단(유의+방향 / 비유의)을 정답으로 둔다.
- k마다 20회 재표본한다. 각 결론에서 판단이 k=100과 같은 비율이 **90% 이상**이면 통과.
- 15개가 모두 통과하는 가장 작은 k를 고른다. k ∈ {5, 10, …, 100}.
- 재표본: 프롬프트마다 원응답 100개(무효 포함)에서 k개를 비복원 추출한다. 실제로 k번 호출한 것과 같다.

## 방법

`run.py` 하나. 순서: 데이터 읽기 → 지표 함수 → k=100 판단 → k별 재표본·판단 → 통과표.

## 결과 (돌린 뒤 쓴다)

표 `out/agreement_by_k.csv`, 그림 `out/agreement_by_k.png`, k=100 판단 `out/verdict_k100.csv`.

- k=100 판단은 기존 보고서(`out_final_k100`)와 같다. F1·F2·F4 추정치는 소수 넷째 자리까지 같고, F3는 사람 쪽 유의쌍을 뽑는 난수 순서가 달라 0.001~0.007 다르다(DeepSeek 0.738 vs 0.731). 유의/비유의 판단은 15개 모두 같다.
- 15개 중 13개는 k=5부터 끝까지 95% 이상 유지된다(F3·F4·F5는 모든 k에서 100%).
- 병목은 하나다: **DeepSeek F2(L0→L1)**. k=100에서 +0.010 [−0.005, 0.027]로 겨우 비유의인데, k가 작으면 추정치가 커져(k=5 +0.022, k=20 +0.016) 가짜로 유의해진다. 유지 비율: k=20 0.30, k=30 0.75, k=40 0.95, k=45 0.80, k=50부터 1.00.
- 규칙상 최소 k는 40이지만, 45에서 다시 떨어지므로 20회 반복의 우연이다. **그 k와 그보다 큰 모든 k가 통과하는 최소값은 50**이다.
- k가 작으면 TVD가 체계적으로 커진다(K-EXAONE F1도 k=5 −0.023 → k=100 −0.061로 작아 보인다). 그래서 비교하는 두 조건은 반드시 같은 k여야 한다.

## 결론

k=100의 결론 15개를 모두 지키는 최소 k는 50(40은 경계, 45에서 다시 실패). 병목은 DeepSeek의 L0→L1 차이 하나로, k가 작으면 잡음 때문에 가짜로 유의해진다.
