## 질문 (돌리기 전에 쓴다)

모델(EXAONE, DeepSeek, Haiku)별로 프롬프트당 표본 수 k를 5~90으로 바꿨을 때 보정 후 validation TVD가 어떻게 줄어드는가. 어디서 평평해지는가(= k를 더 늘릴 가치가 있는가).

## 가설과 판정 기준 (돌리기 전에 쓴다)

- 가설: TVD는 k가 커질수록 줄다가 k≈50 이후 평평해진다. 모델이 사람 분포에서 떨어진 편향이 표집 잡음보다 커서 k를 늘려도 모델 간 순서는 바뀌지 않는다.
- 지지 기준: k=50 → 최대 k의 TVD 감소가 0.01 미만이면 '평평'으로 본다. 기각 기준: 그 구간 감소가 0.01 이상이거나 모델 순서가 바뀐다.
- 반복 간 변동(표준편차)도 같이 보고한다.
- 쓰는 문항 분할: calibration(β·설정 고르기) / validation(확인). test는 쓰지 않는다.

## 방법

count 벡터에서 비복원 추출(다변량 초기하)로 프롬프트당 k개를 뽑는다. 원응답에서 k개를 뽑는 것과 같다(응답 순서는 쓰지 않음). 유효 응답이 k보다 적으면 있는 만큼 쓴다. k ∈ {5,10,20,30,50,70,90}, 반복 5회(시드 고정). 매 (k, 반복)마다 calibration 148문항으로 β를 다시 고르고(그리드 0.05~1.5, 0.01 간격) validation 49문항 TVD를 잰다. 보정은 라플라스 α=1, p ∝ (c+1)^β. test는 쓰지 않는다. 비교용으로 모델 무관한 균등 기준선도 표에 둔다.
