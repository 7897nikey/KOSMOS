## 질문 (돌리기 전에 쓴다)

모델(EXAONE, DeepSeek, Haiku)별로 프롬프트당 표본 수 k를 5~90으로 바꿨을 때 보정 후 validation TVD가 어떻게 줄어드는가. 어디서 평평해지는가(= k를 더 늘릴 가치가 있는가).

## 가설과 판정 기준 (돌리기 전에 쓴다)

- 가설: TVD는 k가 커질수록 줄다가 k≈50 이후 평평해진다. 모델이 사람 분포에서 떨어진 편향이 표집 잡음보다 커서 k를 늘려도 모델 간 순서는 바뀌지 않는다.
- 지지 기준: k=50 → 최대 k의 TVD 감소가 0.01 미만이면 '평평'으로 본다. 기각 기준: 그 구간 감소가 0.01 이상이거나 모델 순서가 바뀐다.
- 반복 간 변동(표준편차)도 같이 보고한다.
- 쓰는 문항 분할: calibration(β·설정 고르기) / validation(확인). test는 쓰지 않는다.

## 방법

count 벡터에서 비복원 추출(다변량 초기하)로 프롬프트당 k개를 뽑는다. 원응답에서 k개를 뽑는 것과 같다(응답 순서는 쓰지 않음). 유효 응답이 k보다 적으면 있는 만큼 쓴다. k ∈ {5,10,20,30,50,70,90}, 반복 5회(시드 고정). 매 (k, 반복)마다 calibration 148문항으로 β를 다시 고르고(그리드 0.05~1.5, 0.01 간격) validation 49문항 TVD를 잰다. 보정은 라플라스 α=1, p ∝ (c+1)^β. test는 쓰지 않는다. 비교용으로 모델 무관한 균등 기준선도 표에 둔다.

## 결과 (돌린 뒤 쓴다)

그림: `out/k_curve.png`. 표: `out/k_curve.csv`(모델×단계×k의 TVD 평균·sd·β 평균), `out/full_data_tvd.csv`(실제 k 전체), `out/uniform_baseline.csv`.

보정 후 validation TVD 평균 (`out/k_curve.csv`, 5회 반복)

| 모델·단계 | k=5 | k=20 | k=50 | k=90 |
|---|---:|---:|---:|---:|
| EXAONE L0 | 0.268 | 0.258 | 0.247 | 0.239 |
| EXAONE L1 | 0.280 | 0.261 | 0.252 | 0.247 |
| DeepSeek L0 | 0.290 | 0.274 | 0.267 | 0.261 |
| DeepSeek L1 | 0.307 | 0.297 | 0.290 | 0.286 |
| Haiku L0 | 0.294 | 0.292 | 0.293 | 0.293 |
| Haiku L1 | 0.292 | 0.288 | 0.287 | 0.286 |

- k=50 → 90 감소: EXAONE L0 0.008, L1 0.005 / DeepSeek L0 0.006, L1 0.004 / Haiku 0.001 이하. 모두 0.01 미만이다.
- c0는 EXAONE·Haiku가 k=20 이후 거의 평평(0.298~0.301)하고, DeepSeek만 0.297에서 0.282로 내려간다.
- 선택된 β는 k가 작을수록 크다(예: EXAONE L0 k=5 0.748, k=90 0.36). 표본이 적으면 분포를 덜 펴야 한다.
- 반복 간 sd는 k=5에서 최대 0.0055, k=90에서 0.0005 이하다.
- 모델 순서: L0는 모든 k에서 EXAONE < DeepSeek < Haiku. L1은 EXAONE이 항상 최저이고 Haiku가 DeepSeek보다 낮거나(k≤70) 거의 같다(k=90: 0.2857 vs 0.2859).
- 어느 모델도 균등 기준선(L0 0.335, L1 0.353)을 넘지 않는다.

## 결론

가설은 기준(k=50→최대 k 감소 0.01 미만, 순서 불변)으로는 지지된다. 다만 EXAONE·DeepSeek의 L0·L1은 k=90에서도 아직 완만히 내려가는 중이라 완전히 평평하다고 하기는 어렵다. Haiku는 k=5부터 거의 평평해 표본을 늘려도 이득이 없다(모델 편향이 지배).
한계: 표본은 k=100 데이터의 비복원 부분집합이라 k=90 근처 점은 서로 독립이 아니다. EXAONE 최대 k는 95~99라 100 이상은 외삽할 수 없다.
