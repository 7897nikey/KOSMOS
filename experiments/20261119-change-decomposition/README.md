# 20261119-change-decomposition (변화의 종류 분해)

| 항목 | 내용 |
|---|---|
| 담당 | 태우 |
| 시작 | 2026-11-19 |
| 상태·결론 | `meta.json` |
| 데이터 | 인칭·화계 실험(`20261119-register-effect`)과 같은 원응답·개수. DeepSeek Eco 추론 끔·추론 low, Haiku 5.5 추론 끔, 페르소나 없음·"한국 성인", 네 문체, 표본 0~49 (k=50). 사람 분포는 `analysis/out_final_k100/counts_k100.npz`의 H |

사람이 읽는 곳에서는 조건을 이름으로 쓴다. 코드·CSV 키에서는 `register-effect`의 약어(문체 A~D, 단계 c0/L0)를 따른다.

## 질문 (돌리기 전에 쓴다)

추론 끔 → low, 페르소나 없음 → "한국 성인", 당신 → 이 사람, 하십시오체 → 해라체가 모델 응답 분포를 **어떻게** 바꾸는가. 분포 전체의 날카로움(최빈 보기로 몰림/퍼짐)인가, 순서형 문항에서 질량이 척도 위·아래로 쏠리는 것인가, 특정 보기만 바뀌는 국소 변화인가.

이유: 보정 식 p ∝ (개수+1)^β는 날카로움만 바꾼다. 어떤 조작이 날카로움 변화라면 조건마다 β를 다시 고르는 지금 방식이 그 효과를 지워 왔을 수 있고, β를 어디서 고정할지도 이 답에 달려 있다.

## 가설과 판정 기준 (돌리기 전에 쓴다)

문항마다 조건 X → 조건 Y에 대해 **p_Y ≈ 정규화( p_X^τ · exp(δ·점수) )**를 최대우도(다항분포, Y의 개수)로 맞춘다. p_X는 (개수+1) 평활. 점수는 문항 보기 코드를 문항 안에서 표준화한 값. τ>1이면 X의 최빈 쪽으로 더 몰림, τ<1이면 퍼짐. δ>0이면 질량이 높은 코드 쪽으로 쏠림.

- 격자: τ 0.05~3.0(로그 간격 0.05), δ −2~2(0.1 간격). (시험 실행에서 사람 쪽 맞춤이 τ 0.2 하한에 자주 걸려 하한을 0.05로 낮췄다. 결과를 보기 전의 수정이다.) 명목형·이진 문항은 δ=0(τ만).
- 모든 조건 쌍에서 같은 분석을 하고, **표집 잡음 기준선**을 같은 파이프라인으로 계산한다. 기준선: 두 조건의 개수를 합친 분포에서 각자 표본 수만큼 다시 뽑아(문항별 50회) 같은 식으로 맞춘 값. 해석은 "관측 − 기준선"(초과분)으로 한다. 50개 표본에서는 τ가 잡음만으로도 1에서 벗어나기 때문이다.
- 문항: calibration + validation 197문항(test 49 제외). 두 조건 표본이 20개 미만인 문항은 뺀다.
- 구간: 문항끼리 짝지은 부트스트랩 95%(2,000회). 다중비교 보정 없음(탐색).

| 지표 | 정의 | 의미 |
|---|---|---|
| 변화 크기 | 두 조건 TVD | 얼마나 움직였나 |
| 날카로움 변화 | ln τ의 문항 평균 | + 몰림, − 퍼짐 |
| 기울기 변화 | δ의 문항 평균(순서형 문항만) | + 높은 코드 쪽, − 낮은 코드 쪽 |
| 설명 비율 | 1 − (맞춘 뒤 TVD ÷ 맞추기 전 TVD). τ만 맞춘 값, τ와 δ를 맞춘 값 | 두 성분으로 설명되는 몫 |
| 국소 변화 | 맞춘 뒤 남은 차이(관측 Y − 맞춘 분포)의 평균을 보기 역할별로: X에서 최빈 보기, 양 끝 보기, 중간 보기 | 설명 안 되는 몫이 어디에 몰리나 |

판정:
- **날카로움이 주성분**: 초과 ln τ의 구간이 0을 안 포함하고, τ만 맞춘 설명 비율의 초과분이 0.3 이상.
- **기울기가 주성분**: 초과 δ의 구간이 0을 안 포함하고, δ를 더한 설명 비율이 τ만의 설명 비율보다 초과분 기준 0.1 이상 큼.
- **국소 변화가 주성분**: 두 성분을 맞춘 뒤 설명 비율의 초과분이 0.3 미만이고 역할별 잔차 평균 한 곳 이상에서 구간이 0을 안 포함.
- 방향 예측은 두지 않는다. 한 조작이 여러 성분에 걸치면 그대로 쓴다.

비교 (설정은 DeepSeek 추론 끔·DeepSeek 추론 low·Haiku 추론 끔 각각):
- 페르소나: 페르소나 없음 → "한국 성인" (당신·하십시오체, 당신·해라체)
- 인칭: 당신 → 이 사람 ("한국 성인", 하십시오체·해라체 각각)
- 화계: 하십시오체 → 해라체 (페르소나 없음 / "한국 성인" 당신 / "한국 성인" 이 사람)
- 문체 결합: 당신·하십시오체 → 이 사람·해라체 ("한국 성인")
- 추론: DeepSeek 끔 → low (두 단계 × 가능한 모든 문체)
- 모델 바꾸기(크기 기준): DeepSeek 끔 → Haiku (두 단계, 당신·하십시오체)
- 사람과의 격차: 각 조건 → 사람 분포. 사람 쪽 개수는 H × 유효 표본 수(NEFF). 기준선 없이 τ·δ만 보고하며, 조건마다 필요한 날카로움 조정이 얼마나 다른지(= β를 묶어도 되는지)를 본다.

결과를 본 뒤 추가한 분석(탐색): 시험 실행에서 τ가 최빈 보기가 바뀐 문항에 끌려갈 가능성이 보여, (a) 최빈 보기가 바뀐 문항 비율, (b) 최빈 보기가 같은 문항만의 ln τ·설명 비율을 더했다. 이 두 가지는 사전 기준이 없다.

범위: 성별×연령 10셀 단계(L1)와 Ultrafast는 이번에 넣지 않는다.

## 방법

`run.py` 하나. 원응답 → 개수 → 비교마다 문항별 (TVD, ln τ, δ, 맞춘 뒤 TVD, 역할별 차이) → 기준선 50회 → 부트스트랩 구간. 출력: `out/comparisons.csv`(비교별 요약), `out/vs_human.csv`, `out/items.npz`(문항별 값), `out/run.log`, `out/run.json`.

(DeepSeek 추론 low의 화계 바꾸기 세 비교는 TVD가 0.09~0.11로 잡음(0.04~0.05)의 약 2배라 작은 변화다. 화계 평균 TVD는 설정별로 DeepSeek 끔 0.17, low 0.10, Haiku 0.24.)

1. **모든 조작에서 변화의 대부분은 "최빈 보기가 바뀌는 문항이 늘어나는 것"과 같이 움직인다.** 최빈 보기가 바뀐 문항 비율이 잡음의 2~4배(화계 0.17, 나머지 0.25~0.30, 모델 바꾸기 0.49)이고, 변화 크기(TVD)와 거의 같은 값이다. 질량은 X의 최빈 보기에서 빠져 **중간 보기로** 간다. 양 끝 보기는 거의 그대로다(조작별 평균 −0.02~+0.02).
2. **τ(날카로움)와 δ(순서 기울기)로 설명되는 몫이 잡음 기준선보다 작다.** 비교 평균 0.45~0.65 대 0.70~0.76. 맞춘 뒤에도 최빈 보기 −0.03~−0.10, 중간 보기 +0.05~+0.19의 잔차가 남고 구간이 0을 안 포함하는 비율이 97%다(32개 중 31개 비교, 역할 세 곳 모두). 사전 기준의 "국소 변화" 쪽에 해당한다. 또 "날카로움이 주성분"·"기울기가 주성분" 기준은 어떤 조작에서도 충족되지 않았다(설명 비율 초과가 31개 비교에서 음수, 최대 +0.01). 단, 이 기준은 잡음에서도 맞춘 몫이 0.7 안팎으로 높게 나오는 구조라 초과분 0.3 이상은 애초에 도달하기 어려웠다. 판정은 "국소 변화 쪽, 날카로움·기울기 쪽 아님"으로 읽되 기준 설계의 한계를 함께 적는다.
3. **날카로움(ln τ)은 모든 문항을 한꺼번에 보면 32개 중 30개에서 잡음보다 유의하게 낮게(퍼지는 쪽으로) 나오지만, 최빈 보기가 바뀐 문항에 끌려간 값이다.** 최빈 보기가 바뀐 문항에서는 τ를 줄여 새 최빈 보기에 질량을 주는 것이 최선이기 때문이다(결과를 본 뒤 추가한 분석). 최빈 보기가 같은 문항만 보면 유의한 비교가 13개로 줄고 크기도 작아진다. 10개는 퍼지는 쪽(−0.10~−0.41: DeepSeek 추론 끔의 페르소나·인칭·화계·문체 결합 7개, 추론 low의 페르소나 2개, Haiku 인칭 1개), 3개는 몰리는 쪽(+0.19~+0.29: 추론 끔→low 2개, DeepSeek 끔→Haiku 1개)이다. 추론 low와 Haiku가 더 몰리는 모델이라는 점과 방향이 맞는다.
4. **기울기(δ)는 대부분 잡음 수준이다.** 유의한 비교는 32개 중 4개다: 추론 끔→low 3개(δ 초과 +0.21~+0.32, 높은 코드 쪽으로 이동)와 Haiku 화계 1개(−0.19).
5. **사람 분포와의 격차**(`vs_human.csv`, 잡음 기준선 없음): 모델 분포를 사람 쪽으로 맞추려면 모든 조건에서 ln τ ≈ −1.2~−1.7(τ ≈ 0.2~0.3, 즉 크게 퍼뜨림)이 필요하고, δ는 −0.02~−0.21(사람이 더 낮은 코드 쪽). 맞춘 뒤 TVD는 맞추기 전 0.36~0.49에서 0.13~0.18로 줄지만 0이 되지는 않는다. 같은 설정 안에서 조건 사이 ln τ 차이는 0.04~0.5다(DeepSeek 추론 low: 페르소나 없음 −1.65, 한국 성인·이 사람 −1.22 ~ −1.36, DeepSeek 끔: −1.21 ~ −1.54, Haiku: −1.48 ~ −1.70). 이 사람 문체가 필요한 퍼뜨림이 가장 작다(사람 쪽에 가까움).

주의:
- ln τ가 격자 끝(0.05 또는 3.0)에 걸린 문항이 비교 사이 평균 47%(15~72%)다(사람 격차는 22%). 한 조건이 거의 한 보기에 몰린 문항에서 생기며, ln τ 평균은 격자 범위 안에서만 읽어야 한다.
- 표본 50개에서 문항당 최빈 보기 판정은 흔들린다(잡음 기준선이 5~12%). 기준선을 뺀 초과분으로 읽었다.
- 성별×연령 10셀 단계와 Ultrafast는 넣지 않았다. 결과를 본 뒤 추가한 것은 최빈 보기 바뀜 분석 두 가지와 τ 격자 하한 조정(0.2→0.05, 시험 실행 뒤)이다.

## 결론

조작을 가리지 않고 변화는 분포 전체를 날카롭게/뭉툭하게 하거나 순서 방향으로 미는 것이 아니라, 많은 문항(화계 17%, 그 외 25~30%, 모델 바꾸기 49%)에서 모델의 최빈 보기에서 질량이 빠져 중간 보기로 옮겨가고 최빈 보기가 바뀌는 국소 재배치다. 크기는 모델 바꾸기 > 페르소나 ≈ 추론 > 인칭 > 화계 순이다. 순서 기울기는 추론 끔→low에서만 일관되게 보인다(높은 코드 쪽).

## 다음

- 중간 보기로 이동한다는 것이 사람 분포 쪽으로의 이동인지 확인한다: 사람 분포에서 중간 보기 비중 대비 모델의 비중, 최빈 보기가 바뀐 문항에서 새 최빈 보기가 사람 최빈 보기와 맞는 비율.
- β 고정 단위 비교(조건별 / 모델×페르소나 / 모델 전체)를 잇는다. 사람 격차의 ln τ가 조건 사이에서 0.04~0.5 달랐으므로 문체끼리 공유하는 단계가 우선이다.
- 최빈 보기가 바뀐 문항이 문항 종류(주제·보기 수)에 몰리는지 본다.
