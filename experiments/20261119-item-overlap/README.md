# 20261119-item-overlap (흔들리는 문항 겹침·성질·방향)

| 항목 | 내용 |
|---|---|
| 담당 | 태우 |
| 시작 | 2026-11-19 |
| 상태·결론 | `meta.json` |
| 데이터 | `20261119-register-effect`와 같은 원응답·개수(DeepSeek Eco 추론 끔·low, Haiku 5.5 추론 끔, k=50)와 사람 분포 H. 문항 속성은 `item_manifest_v2.csv`(주제, 민감도, 바람직한 쪽, 척도 종류, 보기 수) |

사람이 읽는 곳에서는 조건을 이름으로 쓴다. 코드·CSV 키에서는 `register-effect`의 약어(문체 A~D, 단계 c0/L0)를 따른다.

## 질문 (돌리기 전에 쓴다)

`change-decomposition`에서 조작(추론·인칭·화계)을 바꾸면 문항의 17~30%에서 최빈 보기가 바뀐다는 것까지는 확인했다. 어떤 변화인지는 모른다. 이번에는 세 가지를 본다.

1. 조작마다 흔들리는 문항이 같은 문항인가, 제각각인가. (같으면 "문항 성질" 문제, 제각각이면 "조작 효과" 문제)
2. 흔들리는 문항이 어떤 성질(주제, 민감도, 척도 종류, 보기 수, 사람 분포의 몰림)에 몰려 있는가.
3. 최빈 보기가 바뀐 문항에서 새 최빈 보기가 사람 쪽인가 반대쪽인가. 순서형 문항에서는 어느 방향(높은 코드, 바람직한 쪽)으로 옮겨가는가, 그 방향이 설정·조작 사이에 일관되는가.

페르소나(없음 → 한국 성인)는 사람 정답이 같은 모집단이라 변화 재현을 볼 수 없어 이번에 뺀다. 모델 바꾸기도 뺀다.

## 가설과 판정 기준 (돌리기 전에 쓴다)

방향 예측은 두지 않는다. test 49문항은 쓰지 않는다(197문항). 다중비교 보정 없음(탐색).

비교(대표 조합 7개, 전체 21개는 CSV에): DeepSeek 끔·DeepSeek low·Haiku 각각의 인칭("한국 성인", 당신·하십시오체 → 이 사람·하십시오체), 화계("한국 성인", 당신·하십시오체 → 당신·해라체), 그리고 DeepSeek 추론 끔 → low("한국 성인", 당신·하십시오체).

정의:
- **잡음 밖 흔들림**: 두 조건의 문항별 TVD가, 두 조건의 개수를 합친 분포에서 다시 뽑은 TVD(200회)의 95번째 백분위수보다 큰 문항.
- **최빈 보기 뒤바뀜**: 두 조건의 최빈 보기 집합이 겹치지 않는 문항.

| 질문 | 지표 | "있음" 기준 |
|---|---|---|
| 겹침 | 대표 7개 사이 쌍마다 잡음 밖 흔들림 문항의 겹침 수 ÷ 독립일 때 기대 겹침 수, 초기하분포 단측 p, 문항별 TVD 초과의 스피어만 상관 | 비율 1.5 이상이고 p<0.05인 쌍이 과반이면 "겹침 있음". 요약: 7개 중 5개 이상에서 흔들리는 문항 수를 독립 가정 모의(1,000회)와 비교 |
| 성질 | 잡음 밖 흔들림 비율을 사람 1등 비율 3분위, 보기 수, 척도 종류, 주제, 민감도 구간, 바람직한 쪽별로. 비교 7개를 합쳐 | 구간 사이 비율 차이의 부트스트랩 95% 구간이 0을 안 포함 |
| 사람 쪽 | 최빈 보기 뒤바뀜 문항에서 (X는 틀리고 Y는 맞는 수) − (X는 맞고 Y는 틀린 수), 전체 197문항 대비 비율, 부트스트랩 95% | 구간이 0을 안 포함 |
| 방향 | 순서형 문항에서 (a) 점수 이동(표준화한 코드 기댓값의 Y − X)의 문항 평균과 구간, (b) 바람직한 쪽으로 이동한 문항 비율, (c) 뒤바뀐 문항에서 새 최빈 보기 코드가 더 높은 비율 | 구간이 0(또는 비율은 0.5)을 안 포함 |
| 방향 일관 | 같은 조작을 설정 사이, 다른 조작을 같은 설정 안에서 비교한 문항별 점수 이동 스피어만 상관 | 상관의 부트스트랩 95% 구간이 0을 안 포함 |
