# 20261119-item-overlap (흔들리는 문항 겹침·성질·방향)

| 항목 | 내용 |
|---|---|
| 담당 | 태우 |
| 시작 | 2026-11-19 |
| 상태·결론 | `meta.json` |
| 데이터 | `20261119-register-effect`와 같은 원응답·개수(DeepSeek Eco 추론 끔·low, Haiku 5.5 추론 끔, k=50)와 사람 분포 H. 문항 속성은 `item_manifest_v2.csv`(주제, 민감도, 바람직한 쪽, 척도 종류, 보기 수) |

사람이 읽는 곳에서는 조건을 이름으로 쓴다. 코드·CSV 키에서는 `register-effect`의 약어(문체 A~D, 단계 c0/L0)를 따른다.

## 질문 (돌리기 전에 쓴다)

`change-decomposition`에서 조작(추론·인칭·화계)을 바꾸면 문항의 17~30%에서 최빈 보기가 바뀐다는 것까지는 확인했다. 어떤 변화인지는 모른다. 이번에는 세 가지를 본다.

1. 조작마다 흔들리는 문항이 같은 문항인가, 제각각인가. (같으면 "문항 성질" 문제, 제각각이면 "조작 효과" 문제)
2. 흔들리는 문항이 어떤 성질(주제, 민감도, 척도 종류, 보기 수, 사람 분포의 몰림)에 몰려 있는가.
3. 최빈 보기가 바뀐 문항에서 새 최빈 보기가 사람 쪽인가 반대쪽인가. 순서형 문항에서는 어느 방향(높은 코드, 바람직한 쪽)으로 옮겨가는가, 그 방향이 설정·조작 사이에 일관되는가.

페르소나(없음 → 한국 성인)는 사람 정답이 같은 모집단이라 변화 재현을 볼 수 없어 이번에 뺀다. 모델 바꾸기도 뺀다.

## 가설과 판정 기준 (돌리기 전에 쓴다)

방향 예측은 두지 않는다. test 49문항은 쓰지 않는다(197문항). 다중비교 보정 없음(탐색).

비교(대표 조합 7개, 전체 21개는 CSV에): DeepSeek 끔·DeepSeek low·Haiku 각각의 인칭("한국 성인", 당신·하십시오체 → 이 사람·하십시오체), 화계("한국 성인", 당신·하십시오체 → 당신·해라체), 그리고 DeepSeek 추론 끔 → low("한국 성인", 당신·하십시오체).

정의:
- **잡음 밖 흔들림**: 두 조건의 문항별 TVD가, 두 조건의 개수를 합친 분포에서 다시 뽑은 TVD(200회)의 95번째 백분위수보다 큰 문항.
- **최빈 보기 뒤바뀜**: 두 조건의 최빈 보기 집합이 겹치지 않는 문항.

| 질문 | 지표 | "있음" 기준 |
|---|---|---|
| 겹침 | 대표 7개 사이 쌍마다 잡음 밖 흔들림 문항의 겹침 수 ÷ 독립일 때 기대 겹침 수, 초기하분포 단측 p, 문항별 TVD 초과의 스피어만 상관 | 비율 1.5 이상이고 p<0.05인 쌍이 과반이면 "겹침 있음". 요약: 7개 중 5개 이상에서 흔들리는 문항 수를 독립 가정 모의(1,000회)와 비교 |
| 성질 | 잡음 밖 흔들림 비율을 사람 1등 비율 3분위, 보기 수, 척도 종류, 주제, 민감도 구간, 바람직한 쪽별로. 비교 7개를 합쳐 | 구간 사이 비율 차이의 부트스트랩 95% 구간이 0을 안 포함 |
| 사람 쪽 | 최빈 보기 뒤바뀜 문항에서 (X는 틀리고 Y는 맞는 수) − (X는 맞고 Y는 틀린 수), 전체 197문항 대비 비율, 부트스트랩 95% | 구간이 0을 안 포함 |
| 방향 | 순서형 문항에서 (a) 점수 이동(표준화한 코드 기댓값의 Y − X)의 문항 평균과 구간, (b) 바람직한 쪽으로 이동한 문항 비율, (c) 뒤바뀐 문항에서 새 최빈 보기 코드가 더 높은 비율 | 구간이 0(또는 비율은 0.5)을 안 포함 |
| 방향 일관 | 같은 조작을 설정 사이, 다른 조작을 같은 설정 안에서 비교한 문항별 점수 이동 스피어만 상관 | 상관의 부트스트랩 95% 구간이 0을 안 포함 |

## 방법

`run.py` 하나. `register-effect/run.py`의 데이터 준비·load를 그대로 쓴다. 출력: `out/items.csv`(문항×비교 값), `out/overlap.csv`, `out/overlap_summary.csv`, `out/properties.csv`, `out/human_direction.csv`, `out/shift_direction.csv`, `out/shift_corr.csv`, `out/run.log`, `out/run.json`.

## 결과 (돌린 뒤 쓴다)

표는 `out/`의 CSV, 로그 `out/run.log`. 비교 21개(인칭 6, 화계 9, 추론 6), 문항 197개(Haiku 일부 160~190). 대표 7개는 설정 3개의 인칭·화계(한국 성인, 하십시오체 기준)와 추론 끔→low(한국 성인, 당신·하십시오체)다.

**1. 흔들리는 문항은 같은 문항인가** (`overlap.csv`, `overlap_summary.csv`)
- 잡음 밖으로 흔들린 문항 비율: 추론 0.58, 인칭 0.51, 화계 0.34. 최빈 보기 뒤바뀜: 추론 0.29, 인칭 0.25, 화계 0.16.
- 대표 7개 21쌍의 겹침은 독립일 때 기대보다 조금 많다. 비율 1.06~1.62(중앙 약 1.2), 초기하 p<0.05는 17쌍, 비율 1.5 이상이면서 p<0.05는 2쌍(DeepSeek 끔·low의 화계, Haiku의 인칭·화계). 사전 기준("과반")은 **충족되지 않았다**. 다만 흔들림 비율이 0.3~0.6으로 높아 비율 상한 자체가 낮으므로(비율 2가 최대) 이 기준은 엄격했다.
- 문항별 TVD 초과의 스피어만 상관은 −0.05~0.65, 중앙 0.17.
- 7개 중 5개 이상에서 흔들린 문항은 43개로 독립 가정 평균 20.6개의 두 배이고(p<0.001), 한 번도 안 흔들린 문항은 21개로 기대 3.8개의 다섯 배다. 즉 문항마다 흔들림 쉬움이 다르고, 그 부분은 조작과 모델이 달라도 공유된다. 그러나 흔들림 대부분은 조건별로 따로 나타난다.

**2. 흔들림은 어떤 문항에 몰리나** (`properties.csv`, 대표 7개 비교의 문항별 평균, 전체 0.42)
- 사람 1등 비율이 낮은 문항(사람 응답이 갈림)일수록 흔들림이 많다: 하위 1/3 0.52, 상위 1/3 0.35, 차이 −0.165 (구간 −0.25~−0.09).
- 보기 수가 많을수록 많고(3개 0.26, 5개 0.46, 7개 0.60), 명목형 8문항은 0.65로 높다(순서형 0.41).
- 민감도는 차이 없음(상위−하위 +0.026, 구간이 0 포함). 주제별 차이는 문항 수가 적어 구간이 겹친다.
- 한계: 모델 쪽 1·2등 격차는 흔들림 판정과 순환이라 쓰지 않았다. 사람 1등 비율이 낮은 문항은 모델도 1·2등이 비슷해 뒤바뀌기 쉬울 수 있다. 이 효과와 분리하지 못했다.

**3. 최빈 보기가 바뀌면 사람 쪽인가** (`human_direction.csv`, 순변화 = Y가 사람 최빈 보기에 맞는 비율 − X)
- 인칭(당신→이 사람): 6개 중 5개가 양수(평균 +0.033), 유의 1개(DeepSeek low +0.066).
- 추론(끔→low): 6개 중 5개가 양수(평균 +0.050), 유의 1개(이 사람·하십시오체 +0.091).
- 화계(하십시오체→해라체): 9개 중 7개가 음수(평균 −0.029), 유의 2개(DeepSeek 끔 페르소나 없음 −0.096, DeepSeek low 이 사람 −0.051).
- 사람 TVD 변화는 흔들린 문항에 몰린다: 인칭 −0.042(사람에 가까워짐), 화계 +0.031(멀어짐), 안 흔들린 문항은 ±0.002 안팎. 크기는 모두 작다(순변화 ≤ 0.1).

**4. 순서형 문항에서 어느 방향으로 가나** (`shift_direction.csv`, `shift_corr.csv`)
- 점수 이동(표준화 코드 기댓값)은 대부분 0과 구분되지 않는다(유의 4/21). 추론 끔→low의 당신 문체 두 비교에서 +0.09(높은 코드 쪽), DeepSeek low의 인칭 두 비교에서 −0.04~−0.05, Haiku 화계(페르소나 없음)에서 +0.07.
- 바람직한 쪽으로의 이동: 인칭에서 DeepSeek(끔·low) 4개 비교가 모두 0.31~0.41로 0.5보다 유의하게 낮다. "이 사람"은 DeepSeek를 사회적으로 바람직한 쪽에서 멀어지게 한다. Haiku는 0.51~0.52로 없음.
- 같은 조작을 설정끼리 비교한 방향 상관: 인칭 DeepSeek 끔–low +0.39(유의), 화계 끔–low +0.26(유의), Haiku와는 모두 0 근처(−0.04~+0.07). 설정 안에서 조작끼리: DeepSeek 끔의 인칭–추론 +0.48(유의), DeepSeek 끔 인칭–DeepSeek low 화계 −0.34, DeepSeek low 화계–추론 −0.23, Haiku 인칭–화계 +0.36 등 혼재.

## 결론

- **문항 성질은 부분적으로만 설명한다.** 사람 의견이 갈리고 보기가 많은 문항은 어느 조작에서나 잘 흔들리지만, 조작끼리 흔들리는 문항의 겹침은 약하다(독립의 약 1.2배). 흔들림의 대부분은 조건마다 따로 나타나는 조건별 효과다.
- **방향은 하나로 일반화되지 않는다.** 사람 쪽 변화는 인칭·추론이 약하게 가깝게, 해라체가 약하게 멀게 한다. 순서·바람직성 방향은 DeepSeek 계열 안에서만 설정 사이 상관이 있고 Haiku에는 없다. 몇 가지 추세로 묶으려면 모델별로 따로 봐야 한다.
- 이전 `change-decomposition`의 결론(변화는 날카로움·기울기가 아니라 문항별 재배치)과 맞는다. 이번 결과로 보태진 것은 "재배치되는 문항은 조건별로 달라 완전한 공통 패턴은 없고, 일부 문항은 공통으로 취약하다"는 점이다.
